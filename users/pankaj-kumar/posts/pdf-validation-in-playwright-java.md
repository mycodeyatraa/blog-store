# PDF Validation in Playwright Java

Invoices, reports, and receipts generated by web applications are frequently exported as PDF files. Validating page count, text content, and metadata ensures document accuracy.

---

## 1. Architectural Overview

Playwright Java intercepts browser download events to save PDF files to disk. Apache PDFBox then parses the document text, layouts, and properties for assertions.

```
+-------------------------------+       +------------------------------------+
| Playwright Download Handler   | ----> | Web Server (PDF Export Endpoint)   |
| page.waitForDownload()        |       +------------------------------------+
+-------------------------------+
                |
                v Download PDF to local disk
+----------------------------------------------------------------------------+
| Apache PDFBox Parser (Text Extraction, Page Count, Structural Assertions)  |
+----------------------------------------------------------------------------+
```

---

## 2. PDF Utility Service

```java
// src/main/java/com/mycodeyatra/pdf/PdfValidator.java
package com.mycodeyatra.pdf;
 
import org.apache.pdfbox.pdmodel.PDDocument;
import org.apache.pdfbox.text.PDFTextStripper;
 
import java.io.File;
import java.io.IOException;
 
public class PdfValidator {
 
    public static int getPageCount(File pdfFile) throws IOException {
        try (PDDocument document = PDDocument.load(pdfFile)) {
            return document.getNumberOfPages();
        }
    }
 
    public static String getTextContent(File pdfFile) throws IOException {
        try (PDDocument document = PDDocument.load(pdfFile)) {
            PDFTextStripper stripper = new PDFTextStripper();
            return stripper.getText(document);
        }
    }
}
```

## 3. Playwright PDF Download & Validation Test

```java
// src/test/java/com/mycodeyatra/tests/PdfDownloadValidationTest.java
package com.mycodeyatra.tests;
 
import com.microsoft.playwright.*;
import com.mycodeyatra.pdf.PdfValidator;
import org.junit.jupiter.api.*;
 
import java.io.File;
import java.io.IOException;
import java.nio.file.Path;
import java.nio.file.Paths;
 
import static org.junit.jupiter.api.Assertions.*;
 
public class PdfDownloadValidationTest {
    private static Playwright playwright;
    private static Browser browser;
    private Page page;
 
    @BeforeAll
    static void setup() {
        playwright = Playwright.create();
        browser = playwright.chromium().launch(new BrowserType.LaunchOptions().setHeadless(true));
    }
 
    @BeforeEach
    void init() {
        page = browser.newPage();
    }
 
    @Test
    @DisplayName("Download Invoice PDF and Validate Text & Page Count")
    void testPdfInvoiceDownload() throws IOException {
        page.navigate("https://mycodeyatra.com/invoices");
 
        // 1. Intercept Download Event
        Download download = page.waitForDownload(() -> {
            page.click("#download-invoice-1001");
        });
 
        Path downloadPath = Paths.get("target/downloads/invoice_1001.pdf");
        download.saveAs(downloadPath);
        File pdfFile = downloadPath.toFile();
 
        // 2. Perform PDF Structural & Content Assertions
        assertTrue(pdfFile.exists(), "Downloaded PDF file should exist");
        
        int pages = PdfValidator.getPageCount(pdfFile);
        assertEquals(2, pages, "Invoice PDF should contain exactly 2 pages");
 
        String pdfText = PdfValidator.getTextContent(pdfFile);
        assertTrue(pdfText.contains("INVOICE #1001"), "PDF content must contain correct Invoice Number");
        assertTrue(pdfText.contains("Total Due: $499.00"), "PDF content must contain correct total amount");
    }
 
    @AfterAll
    static void tearDown() {
        if (browser != null) browser.close();
        if (playwright != null) playwright.close();
    }
}
```

## 4. Enterprise Best Practices & Comparison Summary

- **Temporary Directories**: Store downloaded PDF files in isolated build target folders (`target/downloads`) for automatic cleanup.
- **Apache PDFBox Integration**: Leverage PDFBox for reliable text, font, and page-count verification.
