# AI Test Generation with Playwright Java

Leveraging Playwright's native `codegen` tool combined with AI LLMs enables rapid generation of production-ready Java test scripts from natural language specifications.

---

## 1. Architectural Overview

The CLI tool records user interactions, outputting raw Playwright Java statements. LLM prompts refine these statements into structured Page Object Model classes.

```
+----------------------------------+       +------------------------------------+
| User Actions on Browser          | ----> | Playwright Codegen Engine          |
| (Click, Type, Select)            |       | (mvn exec:java -Dexec.mainClass...) |
+----------------------------------+       +------------------------------------+
                                                          |
                                                          v Generates Raw Script
+---------------------------------------------------------------------------------+
| LLM Refinement Engine (Converts Raw Playwright Script into POM & JUnit 5 Class) |
+---------------------------------------------------------------------------------+
```

---

## 2. Playwright Codegen CLI Execution Command

```bash
# Execute Playwright Codegen to record Java actions
mvn exec:java -e -Dexec.mainClass=com.microsoft.playwright.CLI -Dexec.args="codegen https://mycodeyatra.com/login"
```

## 3. Generated Playwright Java Test Suite

```java
// src/test/java/com/mycodeyatra/tests/AiGeneratedLoginTest.java
package com.mycodeyatra.tests;
 
import com.microsoft.playwright.*;
import org.junit.jupiter.api.*;
 
import static org.junit.jupiter.api.Assertions.*;
 
public class AiGeneratedLoginTest {
    private static Playwright playwright;
    private static Browser browser;
    private Page page;
 
    @BeforeAll
    static void setup() {
        playwright = Playwright.create();
        browser = playwright.chromium().launch(new BrowserType.LaunchOptions().setHeadless(true));
    }
 
    @BeforeEach
    void init() {
        page = browser.newPage();
    }
 
    @Test
    @DisplayName("AI Refined Login Test Flow")
    void testAiRefinedLogin() {
        page.navigate("https://mycodeyatra.com/login");
        page.getByLabel("Username").fill("qa_user");
        page.getByLabel("Password").fill("Secret123!");
        page.getByRole(AriaRole.BUTTON, new Page.GetByRoleOptions().setName("Sign in")).click();
 
        assertTrue(page.isVisible("#dashboard-container"));
    }
 
    @AfterAll
    static void tearDown() {
        if (browser != null) browser.close();
        if (playwright != null) playwright.close();
    }
}
```

## 4. Enterprise Best Practices & Comparison Summary

- **Role-Based Locators**: Prefer `getByRole()` and `getByLabel()` generated by Playwright over volatile XPath expressions.
- **LLM Prompt Guardrails**: Prompt LLMs to insert proper assertions (`assertThat`) instead of relying solely on implicit waits.
